The Quarantamaula Engine is a custom OpenGL 4.6 engine I've developed over the course of a couple of years in order to learn computer graphics in the process. Some of the features I'll highlight are the following:

- Deferred Shading
- Physically Based Shading
- Screen Space Ambient Occlusion
- Soft Shadows
- Image Based Lighting
- Custom .obj model loader

You can read more about how these features are implemented in the [attached paper](https://pepis74.github.io/assets/pdf/qe.pdf). Here I'll share some images rendered with the engine.
